# Telegram Smart Consultant Bot

Telegram-бот на базе **aiogram 3** и **OpenAI**, который помогает собирать требования к Telegram-боту, анализирует запрос клиента и формирует понятное техническое задание с примерной стоимостью. Параллельно бот ведёт аккуратный лог всех диалогов в отдельный чат.
Протестировать: https://t.me/tggg_aibot

## Возможности

- 💬 Диалоговый мастер-заполнения:
  - приветственное сообщение с кнопкой «Создать заказ»;
  - поэтапный сбор данных:
    - компания и ниша;
    - назначение бота;
    - контактное лицо;
    - уточняющие вопросы;
    - дополнительные пожелания.

- 🧠 Умный консультант (OpenAI):
  - анализирует ответы пользователя;
  - подбирает подходящие функции бота по каталогу услуг;
  - формирует осмысленный ответ с рекомендациями и преимуществами;
  - помогает клиенту определиться с форматами и возможностями бота.

- 📋 Каталог услуг и расчёт стоимости:
  - готовый список модулей и интеграций (ChatGPT, CRM, платежи, уведомления, интеграции с внешними сервисами и т.д.);
  - примерный расчёт стоимости базового бота и дополнительных опций;
  - кнопки:
    - «Оформить заказ»;
    - «Получить подробную смету»;
    - «Связаться с программистом».

- 🧾 Генерация summary заказа:
  - краткое резюме всех ответов клиента;
  - список выбранных услуг;
  - примерный бюджет и формат работы;
  - пригодно для отправки менеджеру или сохранения в CRM.

- 📡 Логирование диалогов:
  - все сообщения пользователя и ответы бота отправляются в отдельный служебный чат;
  - поддержка разных типов сообщений: текст, фото, документы, голосовые, кнопки и т.п.;
  - безопасное экранирование HTML, чтобы лог не ломал форматирование.

- ⚙️ Технические особенности:
  - современный стек: **Python 3.12**, **aiogram 3**, **openai**;
  - асинхронная архитектура;
  - удобная конфигурация через `.env`;
  - готовый **Dockerfile** и `docker-compose.yml` для развёртывания.
